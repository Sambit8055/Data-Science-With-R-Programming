# Healthcare Cost Analysis Using R

Industry-style Data Science portfolio project for Healthcare / Health Insurance / Hospital Operations.

**Tools:** R, tidyverse, ggplot2, scales, caret, randomForest

**Scope:** Analyze healthcare cost, utilization, length of stay, readmission and high-cost cases using 3,000 synthetic records.

**Deliverables**
- healthcare_cost_analysis_dataset.csv
- healthcare_cost_analysis.R
- Healthcare_Cost_Analysis_R_Portfolio_Report.docx

**Interview summary:** Developed an end-to-end healthcare cost analytics solution using R, covering data cleaning, EDA, cost segmentation, visualization, KPI development and Random Forest high-cost case classification.

**Data note:** Synthetic portfolio data; not real hospital, insurer or patient data.
